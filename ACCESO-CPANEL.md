# 🔍 URLs para acceder a tu cPanel de GoDaddy

Intenta acceder directamente a través de estas URLs:

## Opción 1: cPanel directo
```
https://iaseguros.com.co/cpanel
```

## Opción 2: cPanel de GoDaddy
```
https://www.godaddy.com/hosting/web-hosting
```
Luego haz clic en "Manage" (Administrar) junto a tu dominio.

## Opción 3: Desde tu panel actual
1. En el menú lateral izquierdo, haz clic en "Sitio web"
2. Busca "File Manager" o "Administrador de archivos"
3. O busca un botón que diga "cPanel" o "Panel de control completo"

## Una vez en cPanel:
- Busca el ícono "File Manager" (generalmente con un ícono de carpeta)
- Está en la sección "Files" (Archivos)
- Haz clic y accederás al administrador de archivos

## Si aún no lo encuentras:
Contacta al soporte de GoDaddy y di:
"Necesito acceder al File Manager de cPanel para subir archivos a public_html"
