## 🚀 PUBLICAR EN HOSTINGER

### ✅ Paso 1: Archivos Ya Construidos

Los archivos de producción están listos en:
```
C:\proyects\iaseguros\iaseguros-web\dist\iaseguros-web\browser\
```

### 📋 Paso 2: Instrucciones Rápidas

1. **Inicia sesión en Hostinger** → https://www.hostinger.com
2. **Abre File Manager** → Administrador de archivos
3. **Ve a public_html** → Carpeta raíz
4. **Sube todos los archivos** → De la carpeta `browser`
5. **¡Visita tu sitio!** → www.tudominio.com

### 📚 Paso 3: Tutorial Completo

Lee la guía detallada paso a paso:
**[📖 TUTORIAL-HOSTINGER.md](./TUTORIAL-HOSTINGER.md)**

## 🛠️ Desarrollo Local

### Instalar dependencias
```bash
npm install
```

### Servidor de desarrollo
```bash
ng serve
```
Navega a http://localhost:4200/

### Construir para producción
```bash
ng build --configuration production
```
